Framework & Programming Language

Flutter Framework (.dart files, pubspec.yaml): The main framework used to build the cross-platform mobile application.

Dart: The programming language used to write the app's logic and UI (seen in main.dart and firebase_options.dart).

Backend & Cloud Services

Firebase Backend (firebase_options.dart, firebase.json):

Firebase was used as the backend service provider.

This is typically used for:

Firebase Authentication: For customer login/signup.

Cloud Firestore / Realtime Database: For storing products, orders, cart items, and user profiles.

Firebase Storage: For uploading product photos.

Development Tools & Code Editor

Visual Studio Code (VS Code): The primary Code Editor / IDE used.

Git Version Control (.gitignore): Used for source control and tracking changes in the code.

PowerShell / Terminal: Open within VS Code for running commands like flutter run or Firebase CLI tools.

Target Platforms & Structure
Based on the folder structure in the Explorer (android, ios, web, windows,):

Android & iOS: The main deployment targets for the mobile e-commerce app.

Web / Desktop: The project structure is also ready in case you want to build the e-commerce app for the Web or Windows desktop.

Dependency Management

pubspec.yaml: Where external packages/libraries used in the app are listed (for example: state management like Provider/Riverpod/Bloc, HTTP packages, or Firebase SDKs).
